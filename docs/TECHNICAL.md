# 기술 문서

## 디스크 구성
- ISO9660 + UDF 1.02. 주요 파일: `SLPS_258.29`(ELF), `DATA.BIN`(1.3GB 자료 묶음), `BGM.BIN`, `VOICE\*.BIN`, `MOVIE0\MOVIE001.PSS`·`MOVIE002.PSS`
- 실행 파일에는 게임 텍스트가 없어(디버그 문자열뿐) **ELF는 수정하지 않습니다.** 그래서 한글판 CRC가 원본판과 같은 `EE84B8C5` 입니다.

## DATA.BIN (BND 아카이브)
- 헤더 `BND\0` + 항목 5,867개, 항목 = `(id u32, 오프셋 u32, 크기 u32)` (`tools/bnd.py`)
- 하위 BND(중첩): `BND\0`, 전체 크기, 개수, 0, `(id, 오프셋)` × 개수
- 수정한 항목은 ISO 끝에 덧붙이고 BND 표·DATA.BIN 크기(ISO9660 레코드, PVD, UDF 파티션 길이·File Entry, 마지막 섹터 UDF 앵커)만 갱신 (`tools/isobuild.py`, `tools/udf.py`)

## 문자열표(STR 청크)
- `[0x10000][크기][0][그룹 수][문자열 수][표 오프셋][0][0]` + 그룹 단어(3×그룹 수−1: 첫 ID, 끝 ID, (시작 인덱스, 첫 ID, 끝 ID)…) + u32 오프셋 × 문자열 수 + SJIS 문자열(NUL 종료) (`tools/strtab.py`)
- 기체별 커맨드 리스트(62053/62054 하위 3049)는 첫 단어가 0이고 끝 채움이 0xCD인 변형
- 문자열이 길어지면 청크를 다시 만들어 컨테이너 끝으로 옮기고, 컨테이너 헤더 슬롯·레코드의 오프셋만 고칩니다(`tools/inject.py`)
- 미션 파일에는 문자열표 밖에 직접 박힌 대사가 있어, 원래 바이트 길이 안에서 제자리 교체합니다(참조 포인터 불변)
- 표시 제어 태그: `<op()> <sp(n)> <ab(ms)> <ed()> <on()> <off()> <im(n)> <fz(ms)>`, 색 강조 `#c[RRGGBB]…#c`

## 이미지·동영상
- 텍스처 헤더 `[총 크기][픽셀 크기][1][스위즐][TEX0 u64]…`, PSMT4/PSMT8 + CLUT (`tools/tex.py`, `tools/gsmem.py`)
- 다시 그린 이미지: 부팅 주의문(38002/38003 하위 50019), 유닛 제목(62050 하위 50641), 진영·목표 카드 64500~64713 (`tools/images.py`)
- 오프닝 `MOVIE002.PSS`(MPEG-2 640×448, 29.97fps): 박힌 자막 화소를 여러 프레임 통계로 찾아 지우고 한글을 같은 위치·페이드로 합성. 바뀐 GOP 구간만 닫힌 GOP로 다시 인코딩하고 남는 바이트를 0으로 채워 파일 크기를 유지 (`tools/movie.py`, `tools/pss.py`)
